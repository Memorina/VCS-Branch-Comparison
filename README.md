
# VCS Branch Comparison Project

## Introduction
This project demonstrates the creation, modification,
and comparison of Git branches.

## Objectives
- Understand Git branching.
- Learn how to create and switch branches.
- Understand how branches help in development.
- Learn how to compare different branches.

## About Git
Git is a distributed version control system used
to track changes in software projects.

## About GitHub
GitHub is a platform used to host Git repositories
and collaborate with other developers.

## Basic Git Branch Commands

Create a branch:
`git branch branch-name`

Switch branches:
`git switch branch-name`

Create and switch:
`git switch -c branch-name`

View branches:
`git branch`

Compare branches:
`git diff main branch-name`

## Conclusion
Git branching allows developers to work on separate
features without directly changing the main branch.
Branch comparison helps identify differences
between branches.
